# Alina Video Prompt Guide — Image to Video

## Standard Motion Prompt (fit check style)
```
9:16 handheld selfie motion based strictly on the uploaded image, the model checks her outfit like a fit check, slight head tilt, small posture shift to show outfit, gentle clothing adjustment, minimal hand movement, natural breathing motion, confident neutral expression, consistent lighting and background, preserve original composition and appearance
```

## Negative Prompt (always use)
```
smiling, new elements, scene changes, background changes, camera movement changes, exaggerated motion, distortion, morphing, extra limbs, face alteration, blur, low quality
```

## Settings
- **Guidance scale:** 0.55
- **Duration:** 5s
- **Aspect ratio:** 9:16 (inherited from input image)
